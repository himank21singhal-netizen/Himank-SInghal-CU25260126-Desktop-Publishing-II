## Objective
To understand layers and layer masks by creating a travel poster composite using at least three photographs, each on its own renamed layer, blended with layer masks, positioned with the Move and Transform tools, on a suitable background with a title, supporting text and at least one layer style such as Drop Shadow or Outer Glow.

## Tools Used
- Layers Panel (separate, renamed layers)
- Layer Masks with the Brush and Gradient Tools
- Move Tool
- Free Transform (Edit > Free Transform)
- Layer Styles (Drop Shadow / Stroke / Outer Glow)
- Horizontal Type Tool
- Gradient Tool (background)

## Output
The final artwork was created using Adobe Photoshop and exported as JPG.
